# WeatherAvatar

A dynamic Flask web application that brings weather experiences to life with personalized avatars that change based on current weather conditions.

## 🌟 Overview

WeatherAvatar is designed for iterative development based on UI mockups. The application provides a solid foundation with Flask backend, responsive Bootstrap frontend, and a clean project structure ready for feature implementation.

## 🚀 Features

- **Real-time Weather Data**: Accurate weather information for any location
- **Dynamic Avatars**: Personalized avatars that adapt to weather conditions
- **Responsive Design**: Beautiful interface that works on all devices
- **Iterative Development**: Ready for mockup-based feature implementation
- **Modern Tech Stack**: Flask, Bootstrap 5, and vanilla JavaScript
